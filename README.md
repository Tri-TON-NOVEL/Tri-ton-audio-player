# Tri-TON Audio Player (PWA) — prototype v0.1.0

GitHub Pages で公開できる、音楽練習・英語リスニング用のローカルファースト音声プレーヤーです。

## 実装済み

- 端末から複数音声ファイルを取り込み、IndexedDB に保持
- 再生、一時停止、前曲・次曲、シーク、音量、シャッフル
- 0.1〜2.0 倍速、ピッチ維持の切替（ブラウザー依存）
- 1曲リピート・全曲リピート・オフ
- A-B 区間指定、区間リピート、0〜60秒の休止時間
- 複数再生リストの作成、曲追加・削除、並べ替え
- ブックマーク、秒戻し・秒送り
- Web Audio API の3バンドEQ（ユーザー操作で有効化）
- 標準音楽・音楽練習・英語リスニング・オーディオブックの4プロファイル
- 簡易/詳細表示の切替、プロファイル複製と簡易表示項目の編集
- 設定JSONのエクスポート・インポート（**音声データは含まれません**）
- PWAインストール・アプリシェルのオフラインキャッシュ設定
- GitHub Actions から GitHub Pages へ自動デプロイ

## 未実装・制限

- AIFF/WMA/APE/DSF等のブラウザー非対応形式の追加デコーダー
- 詳細な波形、キー変更、速度自動変更、メトロノーム、スリープタイマー
- 0.1倍速での高品質タイムストレッチ（現状はブラウザーの playbackRate）
- iOSでのバックグラウンド連続再生保証
- 端末間同期および音声ファイルを含む一括バックアップ
- アプリ更新通知の専用UI、詳細な再生状態テスト

再生可能なファイル形式、低速時の挙動、保存容量はブラウザーと端末に依存します。

## 開発

```bash
npm install
npm run dev
npm run build
```

Node.js 22 推奨。依存パッケージの取得にはインターネット接続が必要です。

## GitHub Pages 公開

1. このフォルダを GitHub リポジトリに push します（ブランチ名: `main`）。
2. GitHub リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にします。
3. `.github/workflows/deploy.yml` が自動的に Vite ビルドと公開を実行します。
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` をブラウザーで開きます。

`vite.config.ts` の base は Actions が `BASE_PATH` に設定します。独自ドメインやルートサイトへ公開する際は変更してください。

## データについて

音声は取り込み時に IndexedDB に**複製して保存**されます。大量の音声ではストレージ容量制限にご注意ください。サイトデータの消去やブラウザー変更によって失われることがあります。
